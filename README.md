> # CP04-Python-Connect4
> Este repositório tem como objetivo controlar as versões do projeto Connect 4 para a entrega do Checkpoint 4 de python.
> ### O Jogo
> O connect 4 é um jogo de tabuleiro clássico onde dois jogadores disputam entre si para ver quem consegue formar uma linha - seja na horizontal, vertical ou diagonáis - de quatro fichas primeiro. As fichas são separadas em duas cores distintas(geralmente amarelo e vermelho) e cada jogador escolhe a cor que deseja. O tabuleiro é formado por uma matriz 6x7 e esse tabuleiro é preenchido de baixo para cima. Os jogadores realizam suas jogadas de forma alternada, ou seja, um por vez, e decidem a estratégia com base nas jogadas anteriores e no nível de preenchimento do tabuleiro.
